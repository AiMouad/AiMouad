## Featured Projects

### 🧠 [Alzheimer's Disease Detection](https://github.com/AiMouad/Deep-Learning-Based-Alzheimer-s-Disease-Detection-Using-Multimodal-ADNI-MRI-and-PET-Imaging)
Multimodal deep learning system for early Alzheimer's diagnosis using ADNI MRI + PET data.
- **Stack:** Python · TensorFlow/Keras · React · Framer Motion · Tailwind CSS
- **Classes:** CN · EMCI · LMCI · AD (stratified 70/15/15 split)
- **Pipeline:** Custom preprocessing with CSV-based metadata, structural MRI filtering, multi-format PET support

### 📱 [A7jazli](https://github.com/AiMouad/A7jazli-for-stadiums-flutter)
Cross-platform sports stadium reservation app built with Flutter.
- **Stack:** Flutter 3.29 · Dart · Firebase · Provider · GoRouter · Material 3
- **Features:** GPS-based distance filtering, real-time booking, animated splash screen
